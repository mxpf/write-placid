# Write Placid Core 1.7.1

This maintenance release updates Studio's icons and the development tools. Writing, private drafts, and publishing controls keep their existing behavior.

## What changed

- **Updated Studio icons.** Studio uses Lucide React 1.51.0. The core also retains its existing 0.x support; the peer range is `>=0.468.0 <1 || ^1.51.0`.
- **TypeScript 7.** Site, Studio, and Drafts MCP run TypeScript 7.0.2 for type checks, and the core uses it for its build. Site and Studio keep Microsoft's TypeScript 6 compatibility API for lint tools. The included commands select the compiler explicitly.
- **Compatible Studio lint tools.** Studio uses ESLint 10.15.0 with supported React and accessibility plugins. A scoped matcher update fixes a vulnerable dependency in the accessibility plugin. Nine regression checks cover React, hooks, TypeScript, Next.js, and accessibility rules.
- **Updated development checks.** Site uses globals 17.13.0. GitHub workflows use checkout and setup-node v7. The full check command now includes Site and Studio's type checks as well as Drafts MCP's. CI and Site's Node types stay on Node 22.
- **Refreshed core files and guides.** The prebuilt JavaScript, declarations, and source maps come from TypeScript 7. The guides explain the compiler and lint compatibility setup.

## Upgrading

Public snapshot contract `1` is unchanged. This release needs no writing or private-draft data migration.

1. Read the [setup guide](../SETUP.md#upgrade-to-171). For upgrades from before 1.7.0, also read the [1.7.0 client upgrade notes](v1.7.0.md#upgrading-an-existing-installation).
2. Pin `mxpf-write-placid-core-1.7.1.tgz` from this GitHub release, verify it against `SHA256SUMS.txt`, and commit the updated lockfile. Update Site and Studio together. Keep your content, identity, credentials, storage connections, and publishing settings in place.
3. For development from the repository, run `npm run setup` with Node 22 (22.13 or newer). Keep Site and Studio's two TypeScript aliases: `typescript-compiler` runs 7.0.2, and `typescript` provides the compatibility API. Drafts MCP installs TypeScript 7 directly. The prebuilt core package works without a compiler or sibling checkout.
4. Run the [release and downstream checks](../CORE.md#release-gate) for your installation before choosing to deploy. The package's declarations are checked with both TypeScript 7 and TypeScript 6.

The demo keeps publishing disabled and **Publish** hidden. GitHub release publication is separate from deploying a site or Worker. Other installations keep their current version until upgraded separately.
